# About SkillSphere
SkillSphere it's a online course platform where has user registration, login, procted routes, all courses and profile management feature. 


##  Live Website
https://b13-a8-skill-sphere-9vik.vercel.app/



##  Tech Stack
Here i've used next js, tailwind, mongoDB, better auth, react toastify and for deployment i've used vercel.

Course archive page functionality
Course single page dynamically with json and this page is proceted
Profile name can changed
Course search from archive page
